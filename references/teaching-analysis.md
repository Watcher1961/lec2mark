# 从教材教学组织到笔记设计

设计参考：Gilbert Strang，Introduction to Linear Algebra，第 5 版；Bjarne Stroustrup，Programming: Principles and Practice Using C++，第 3 版。前者参考向量、矩阵、投影与特征值相关章节；后者参考函数、程序构建、类与练习组织相关章节。

以下是本技能综合形成的设计判断，不是两位作者共同命名的方法。发布时未重新评审原著，不提供原书内容的替代版本，也不分发书内图表、代码或习题。

## 需要保留的教学连接

| 笔记中的问题 | 设计动作 | 复核方式 |
| --- | --- | --- |
| 学生认得符号却不知道表示什么 | 用小例子连接对象、操作与准确名称 | 学生能在例子和定义之间指出对应关系 |
| 公式像突然出现的口诀 | 把目标转成成立条件，再解释如何得到计算步骤 | 用原条件检查结果，区分数值验证与一般证明 |
| 换一道题就不会选择方法 | 改变关键条件并比较结果 | 要求解释何时仍成立、何时失效 |
| 程序能运行但不知道为何这样设计 | 连接输入、状态、输出与设计约束 | 用一个失败输入说明修复范围和剩余限制 |
| 例子很多但知识互不相连 | 保留能贯穿主题的主例，逐步增加条件 | 后续解释能回指前面已经建立的关系 |

不把“先实例后定义”变成绝对规则。参考笔记可以先给结论导航；初学讲解则应补足从具体到抽象的推理。类比、图和代码只在增加理解时使用。

## 练习与反馈

分开检查基本操作、概念解释与新条件下的判断。支持性示范后给独立尝试，答案解释理由、错因及修正方法。固定题量、标题齐全或一次答对不能证明长期掌握。

本包的示例笔记演示这些设计选择；实际处理课程材料时，应优先核对课程原例，保留来源与适用条件。教师原题、教学改写和本技能编写的例子分别说明，不能互相冒充。
