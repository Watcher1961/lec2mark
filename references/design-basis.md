# 学习设计依据与取舍

本文件用于维护、解释或审查技能，无需每次写笔记都加载。以下为设计阶段的参考归属；发布时未重新核对全部原著。这里的 Markdown 组织是教学改编，不是原作者规范，也不构成学习效果保证。

## 学习差距与实际表现

参考 Julie Dirksen，Design for How People Learn，Second Edition，New Riders（2016），尤其有关学习差距、目标、记忆、知识、技能、习惯与评价的章节。

本技能据此选择支持方式：概念误解需要解释和反例，知道但不会做需要示范与撤除支架，环境障碍需要可用资源。目标写成可观察任务，练习与反馈应检验同一种能力。课堂中的证明、解释和方法辨别同样是实际表现，不要求所有内容改写成职场案例。

这是本技能的综合设计，不复制原书的图表、题目或章内编排。比喻不作为精确脑机制，方法也不转换成人人适用的效果百分比。

## 4MAT 的归属与改编

- [About Learning：四个学习问题](https://aboutlearning.com/2017/08/15/about-the-learning-cycle-a-journey-through-the-4mat-quadrants/)
- [4MATion User Guide](https://www.4mat4business.com/downloads/4MATion-User-Guide.pdf)，四问与八步参见文件页 14–15；不同版本须重新定位。

4MAT 名称、四问与步骤名称属于所引用框架。本技能借其检查意义、概念、应用与整合的学习机会，再将其改编为笔记中的解释、练习、反馈与迁移。没有复制官方图轮、手册正文或品牌图像，也不表示获得官方认证或背书。

四问不用于给学生分类；不根据左右脑偏好、固定学习风格或风格匹配承诺教学效果。不强制四个标题、固定顺序或均分篇幅。用户只要短篇或局部修改时，按其实际范围提供支持。
